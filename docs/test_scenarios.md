# Сценарії функціонального тестування (для розділу 3 записки)

> ШІ: Claude Code, Claude Opus 5.5 – перелік сценаріїв і очікуваних результатів.
> Колонку «Фактичний результат» заповнює студент сам після запуску, до кожного сценарію – скриншот.

Запуск: `.venv\Scripts\python.exe main.py`
